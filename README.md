# EduPro-Data-Analytics
Learner Demographics and Course Enrollment Behavior Analysis
EduPro Data Analytics

Overview
This project analyses learner demographics, course enrolment patterns, and transaction data to identify trends and insights in online education.

Files


app.py – Main application
users.csv – Learner data
courses.csv – Course information
teachers.csv – Teacher information
transactions.csv – Enrolment and payment data


Technologies
Python
Pandas
Streamlit


Installation
pip install -r requirements.txt


Run
streamlit run app.py
